# neurofoto-landing — лендинг сбора заявок на визуальный сторителлинг (нейрофото). MVP.


Учебный MVP: одностраничный сайт, который собирает заявки на услугу
«визуальный сторителлинг» — серии нейрофото в едином стиле и сюжете
по референсу клиента.

## Живое демо

https://neurofoto-landing.vercel.app

## Что умеет

- Адаптивная вёрстка (мобильные сетки 4→2→1 колонки)
- Блок референсов «исходный вид» + витрина из 8 стилей
- Пакеты и цены (TEST / 5 / 10 / 15) с пояснением выгоды
- Форма заявки: валидация, защита от двойной отправки, состояния успеха/ошибки
- Заявки приходят в сообщения сообщества ВК через serverless-функцию `/api/lead`
- Автодеплой на Vercel при каждом пуше в main

## Технологии

- HTML / CSS / vanilla JavaScript
- Vercel: статика + serverless-функция `api/lead.js`
- VK API (`messages.send`), токен — только в env-переменных
- Git / GitHub

## Структура

- `index.html` — лендинг (7 блоков)
- `style.css` — дизайн и адаптивность
- `script.js` — валидация и отправка формы
- `api/lead.js` — серверная валидация и отправка заявки в ВК
- `img/` — изображения витрины

## Запуск локально

1. `git clone https://github.com/PavlenkoSergeySerg/neurofoto-landing.git`
2. Открыть `index.html` в браузере (или Live Server).
3. Форма в полную силу работает на Vercel: там заданы env `VK_TOKEN` и `VK_USER_ID`.

## Безопасность

- Токен ВК не хранится в коде и не попадает в браузер — только env на Vercel
- Серверная валидация всех полей (браузеру не верим)
- `.env` в `.gitignore`
